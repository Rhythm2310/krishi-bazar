# UIU Calculator

A public, fully client-side CGPA/GPA and tuition-fee-breakdown calculator for students of United International University (UIU), Bangladesh.

## How to run

1. Install dependencies:
   ```bash
   bun install
   ```

2. Run development server:
   ```bash
   bun run dev
   ```

3. Run tests:
   ```bash
   bun test
   ```

4. Run smoke test (heartbeat):
   ```bash
   make smoke
   ```
   Or without make:
   ```bash
   bun run smoke
   ```
