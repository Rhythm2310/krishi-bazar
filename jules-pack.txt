# Spec: UIU Calculator — Cgpa and tuition + registration money planner

Architect-owned. Agents read it; they never edit it. User stories are `U<n>`, seams are `S<n>`. Task files cite both.

## Problem Statement

A UIU Student cannot answer two basic questions before registering for a Term without hand arithmetic and the official fee PDFs: "What Cgpa will I have if I take these Courses with these grades?" and "Exactly how much Taka do I owe this Term, and when is each part due?" The official fee table publishes per-Credit rates, TermFees, LabFees, one-time AdmissionFee and CautionMoney, waiver tiers and an installment schedule, but nothing combines them with the credit-weighted grade math for a concrete Term plan.

## Solution

A web app (SvelteKit, deployed to Vercel) where a Student picks their Program, enters the Courses of the Term they are planning (CourseCode, Credits, expected LetterGrade, Retake flag), and immediately sees: the TermGpa of the Planner, the Cgpa across all SavedTerms plus the Planner with the degree-requirement 2.00 indicator, an itemized FeeBreakdown in Taka (tuition gross/net with RetakeWaiver and WaiverTier, TermFee, LabFee, FirstTerm one-time charges with the refundable CautionMoney shown separately), and the official PaymentSchedule (Tk 20,000 PreRegistrationPayment then 40/30/30 or 4×25% Installments). SavedTerms persist in the browser. Every screen shows the data EffectiveDate, official sources and a "UIU may change fees without notice" disclaimer.

## User Stories

1. **U1**: As a Student, I want to add, edit and remove Courses in the Planner for one Term — CourseCode, optional title, Credits (0.5 steps, 0.5–12) and expected LetterGrade — so that I see the credit-weighted TermGpa and EarnedCredits update as I plan, with F earning no Credits but counting in the average.
2. **U2**: As a Student, I want to flag a Course as a Retake, so that the earlier attempt with the same CourseCode is replaced in the Cgpa (latest Term wins) and the retaken Credits receive the 50% RetakeWaiver in my fee estimate, visibly labelled as first-time-only.
3. **U3**: As a Student, I want to save the Planner as a SavedTerm with a label, list my SavedTerms, and rename or delete them in my browser, so that my history survives reloads and visits without any account.
4. **U4**: As a Student, I want to see my Cgpa credit-weighted across all SavedTerms plus the Planner, so that I can track progress toward the degree requirement Cgpa 2.00 with a clear below/at-or-above indicator.
5. **U5**: As a Student, I want to select my Program and see the FeeBreakdown for my planned Credits — tuition at the Program's PerCreditFee (Tk 6,500; Tk 5,525 for BA English and BSSMSJ), plus the TermFee (Tk 6,500 Trimester; Tk 9,750 Semester) and the Program's LabFee — itemized in Taka, so that I know exactly what I owe for the Term.
6. **U6**: As a Student in my FirstTerm, I want the one-time AdmissionFee (Tk 20,000, non-refundable) and CautionMoney (Tk 2,000, refundable) included and separately labelled, so that my first-Term total is complete and I know what I get back.
7. **U7**: As a Student with a scholarship or waiver, I want to select a WaiverTier (0, 25 or 50 percent) and see the reduced tuition with a "conditions apply — official totals may differ" note, so that I get an honest estimate of what I pay.
8. **U8**: As a Student, I want the PaymentSchedule for the Term — Tk 20,000 PreRegistrationPayment, then the remaining dues in the official Installments (Trimester 40/30/30; Semester 4 × 25%) — so that I can plan my cash flow, and on a FirstTerm I want it stated that the AdmissionFee counts as that Term's PreRegistrationPayment.
9. **U9**: As a Student or visitor, I want every result area, the page footer and the README to show the data EffectiveDate, links to the official uiu.ac.bd grading and fees pages, and a "UIU may change fees without notice — verify before paying" disclaimer, so that I never mistake an estimate for an invoice.

## Implementation Decisions

- Stack: SvelteKit 3 with Svelte 5 runes, TypeScript 6 strict, Vite 8, deployed with the Vercel adapter; the Node.js runtime requirement is met by Vercel's Node functions and by Node 24 LTS everywhere the code runs (CI, Jules snapshot, local). The whole app prerenders to static output: no server logic, no API routes.
- Package management: npm with a committed lockfile; every version exactly pinned per the dependency ledger; zero production dependencies — everything is a devDependency because the deployed artifact is static.
- Architecture: three pure domain modules — grading, cgpa, fees — behind one frozen contract of shared types and function signatures. Domain code never imports Svelte, routing or storage. One Planner page composes panels that call domain functions. A versioned localStorage key holds Student state (ADR 0001); a state module owns load/save and guards server-side rendering.
- Grade math: GradePoints exactly as published (A 4.00, A- 3.67, B+ 3.33, B 3.00, B- 2.67, C+ 2.33, C 2.00, C- 1.67, D+ 1.33, D 1.00, F 0.00). TermGpa and Cgpa are Σ(Credit × GradePoint) / Σ(Credit) at full precision, displayed rounded to 2 decimals. EarnedCredits exclude F Courses.
- Retake rule: within Cgpa, Courses are deduplicated by normalized CourseCode (trim, collapse spaces, case-insensitive); the latest Term's attempt wins and the replaced codes are reported to the UI. The Retake flag itself only drives the RetakeWaiver in fees. (The official grading page does not state the replacement rule explicitly — recorded as an assumption to verify against UIU regulations.)
- Fee math, per Term: tuitionGross = Credits × PerCreditFee; retakeWaiver = retakeCredits × PerCreditFee × 0.5; tierWaiver = (Credits − retakeCredits) × PerCreditFee × tier/100 (official rule: waivers never apply to Retake credits, TermFee, LabFee or one-time charges); totalDue = tuitionGross − retakeWaiver − tierWaiver + TermFee + LabFee + (FirstTerm ? 20,000 + 2,000 : 0); refundable = FirstTerm ? 2,000 : 0. Waiver amounts are estimates: UIU's published 25%/50% program totals do not reproduce exactly from the public formula, so the UI and README carry the "conditions apply" pointer.
- Whole-degree total (used by tests and available to the UI): Credits_total × PerCreditFee × (1 − tier/100) + termsTotal × (TermFee + LabFeePerTerm) + AdmissionFee. At tier 0 this equals the official published totals exactly for every Program (validated: BSCSE 1,014,500; BA English 777,575; B.Pharm 1,178,000; BSBGE 1,032,000; BSc Civil 1,082,750).
- PaymentSchedule: preRegistration = 20,000; remaining = max(0, tuitionNet + TermFee + LabFee − 20,000); split 40/30/30 (Trimester) or 25/25/25/25 (Semester) with the rounding remainder added to the last Installment; on a FirstTerm the note states the AdmissionFee counts as the PreRegistrationPayment.
- Money: computed in exact Taka (halves possible at the 5,525 rate), never floats-formatted mid-computation; displayed with up to 2 decimals and en-IN digit grouping (Tk 1,26,000). GPA/CGPA displayed with exactly 2 decimals.
- Domain validation: invalid Credits (not a positive multiple of 0.5 up to 12), unknown ProgramId, retakeCredits > creditsPlanned or an unknown LetterGrade throw RangeError with a one-line message; the UI prevents invalid input and catches at the boundary with inline messages — never alert dialogs.
- Shared state shape (from the contract prototype, encoding the decision prose cannot):

```ts
// from prototype: the frozen core shapes every module speaks
interface CourseEntry { id: string; code: string; title: string; credits: number; grade: LetterGrade; isRetake: boolean }
interface TermRecord  { id: string; label: string; courses: CourseEntry[] }
interface FeeInput    { programId: ProgramId; creditsPlanned: number; retakeCredits: number; isFirstTerm: boolean; waiverTier: 0 | 25 | 50 }
```

- Data: the 11-grade scale, the 12-Program fee table and the fee constants are frozen data modules carrying EffectiveDate 2026-10-23 and the two official source URLs; fee updates happen only through an amendment task, never by an agent.
- UI language English; currency Taka (Tk); accessible by default (native form controls, every input labelled, results in aria-live regions).

## Testing Decisions

```ts
import type { CalculateTermGpaFn } from '../contracts';
import { gradePoint } from './grade-point';

export function assertCredits(credits: number): void {
	if (!Number.isFinite(credits) || credits <= 0 || credits > 12 || (credits * 2) % 1 !== 0) {
		throw new RangeError('credits must be a positive multiple of 0.5, at most 12');
	}
}

export const calculateTermGpa: CalculateTermGpaFn = (courses) => {
	let totalCredits = 0;
	let earnedCredits = 0;
	let weighted = 0;
	for (const course of courses) {
		assertCredits(course.credits);
		const point = gradePoint(course.grade);
		totalCredits += course.credits;
		weighted += course.credits * point;
		if (point > 0) {
			earnedCredits += course.credits;
		}
	}
	return {
		gpa: totalCredits === 0 ? 0 : weighted / totalCredits,
		earnedCredits,
		totalCredits
	};
};
```

Done means: every story U1–U9 in `.jules/spec.md` green at seams S1/S2, `npm run verify` green, and a README that states the data EffectiveDate and the "verify with UIU before paying" disclaimer.

## 2. Operating contract

1. You are one of several agents running concurrently in separate VMs. You cannot see or talk to the others. The repo is the only channel.
2. Open `.jules/tasks/<TASK_ID>-*.md` and execute only that task. Do not start other tasks, do not "helpfully" fix unrelated things.
3. Work autonomously. Never ask the user a question and never wait for approval. When something is ambiguous, apply the decision defaults in section 6, record the choice in your report, and keep going.
4. Change only the paths your task owns (section 5). Everything else is read-only.
5. Work test-first at the seams your task lists (skill `tdd`), review your own diff on both axes (skill `code-review`), then finish with: green verify command, clean `slop_guard`, a report at `.jules/reports/<TASK_ID>.md`, one PR.

Runtime: Node.js 24 (CI and the Jules snapshot pin 24.22.1), npm as shipped with Node 24. Python 3.12 runs the guard tools. Browsers: Chromium for the S2 seam.
Dependencies: every package and version is pinned in `.jules/deps.csv` (researched stable, non-deprecated releases). Use exactly those versions.

# UIU Calculator glossary

Language only. No implementation detail, specs or scratch notes. One word per concept; the "Avoid" list names the synonyms nobody uses.

## Terms

**Student**: the person using the app; a UIU undergraduate planning or reviewing a Term.
_Avoid_: user, client, person

**Program**: one of the 12 official UIU undergraduate programs in the fee table (for example BSCSE or B.Pharm), carrying its PerCreditFee, total Credit requirement and TermSystem.
_Avoid_: department, faculty, major, course-of-study

**Term**: one teaching period at UIU; either a Trimester or a Semester depending on the Program.
_Avoid_: semester (alone), trimester (alone), session, quarter

**Trimester**: the Term system used by every Program except B.Pharm; 12 Trimesters per degree; TermFee Tk 6,500.

**Semester**: the Term system used by B.Pharm only; 8 Semesters per degree; TermFee Tk 9,750.

**Course**: one subject a Student plans or completed in a Term, identified by its CourseCode, with Credits and a LetterGrade.
_Avoid_: subject, class, module, paper

**CourseCode**: the official UIU identifier of a Course (for example `CSE 1101`); the key that identifies a Course across Terms for Retake replacement.
_Avoid_: course name (that is the title), course id

**Credit**: the weight of a Course; multiples of 0.5, range 0.5 to 12 per Course.
_Avoid_: credit hour, unit, point (point is the GradePoint)

**LetterGrade**: one of the 11 official UIU grades: A, A-, B+, B, B-, C+, C, C-, D+, D, F.
_Avoid_: grade letter, mark, score

**GradePoint**: the numeric value of a LetterGrade (A = 4.00 down to D = 1.00; F = 0.00).
_Avoid_: point value, grade value

**TermGpa**: the Credit-weighted average GradePoint of the Courses in one Term; F Courses count in the denominator and earn no Credits.
_Avoid_: GPA (alone), semester GPA, SGPA

**Cgpa**: cumulative GradePoint average: the Credit-weighted average GradePoint across all SavedTerms plus the Planner, after Retake replacement. Degree requirement: 2.00.
_Avoid_: GPA (alone), cumulative GPA, average

**EarnedCredits**: Credits from Courses graded D or higher; an F earns nothing and the Course must be retaken.
_Avoid_: completed credits, passed hours

**Retake**: re-registering for a Course after an F or for grade improvement; the new attempt replaces the earlier attempt with the same CourseCode in Cgpa, and its Credits get the RetakeWaiver the first time.
_Avoid_: repeat, retake-course, improvement (alone)

**RetakeWaiver**: the 50% reduction of the tuition charge on Retake Credits (first retake of a Course only, per official policy).

**SavedTerm**: a Term the Student finished planning and stored in the browser; has a label and its Courses. SavedTerms feed the Cgpa.
_Avoid_: history entry, archive

**Planner**: the Term currently being edited on the page; it counts toward Cgpa and fee estimates but is not a SavedTerm until saved.

**FeeBreakdown**: the itemized money due for one Term: tuition (gross, waivers, net), TermFee, LabFee, and on a FirstTerm the AdmissionFee and CautionMoney, plus the total.
_Avoid_: bill, invoice, cost summary

**FeeLine**: one row of a FeeBreakdown with a label, an amount in Taka (waivers are negative) and a kind.

**PerCreditFee**: the tuition charge per Credit of a Program: Tk 6,500, or Tk 5,525 for BA English and BSSMSJ (15% discount).
_Avoid_: credit rate, tuition rate

**TermFee**: the fixed registration charge per Term: Tk 6,500 per Trimester; Tk 9,750 per Semester (B.Pharm). This is what students colloquially call the "registration fee".
_Avoid_: registration fee (ambiguous with AdmissionFee), semester fee (alone)

**LabFee**: the per-Term laboratory charge of specific Programs: BSBGE Tk 2,000 per Trimester; B.Pharm Tk 5,000 per Semester; Tk 0 for every other Program.

**AdmissionFee**: the one-time Tk 20,000 non-refundable down payment made at admission; on a FirstTerm it counts as that Term's PreRegistrationPayment.
_Avoid_: admission cost, registration fee

**CautionMoney**: the one-time Tk 2,000 refundable ID-card deposit paid at admission; shown separately as refundable in the FeeBreakdown.
_Avoid_: deposit, security

**FirstTerm**: the Student's very first Term at UIU, when AdmissionFee and CautionMoney apply.

**WaiverTier**: the scholarship/waiver percentage a Student selects: 0, 25 or 50; it reduces tuition on non-Retake Credits only. Computed values are estimates: official conditions apply.
_Avoid_: scholarship (alone), discount

**PaymentSchedule**: how one Term's dues are paid: the PreRegistrationPayment of Tk 20,000, then the remaining amount in Installments (Trimester: 40/30/30; Semester: 4 × 25%).
_Avoid_: installment plan (that is part of it), payment plan

**PreRegistrationPayment**: the Tk 20,000 partial tuition payment required before course registration of each Term.

**Installment**: one of the scheduled partial payments of the remaining Term dues after the PreRegistrationPayment.

**Taka**: the currency (BDT, symbol Tk) of every amount in the app; amounts may end in .5 and are displayed with up to 2 decimals and en-IN digit grouping (Tk 1,26,000).
_Avoid_: BDT (in UI text), taka sign, dollars

**EffectiveDate**: the date (2026-10-23) the fee and grading data was taken from uiu.ac.bd; displayed with every result and in the footer because UIU may change fees without notice.
_Avoid_: last updated (use EffectiveDate)

## Relationships

- A Program has one TermSystem, one PerCreditFee, a total Credit requirement and a LabFeePerTerm.
- A Term contains many Courses; a Course belongs to exactly one Term.
- A Student keeps many SavedTerms plus exactly one Planner.
- Cgpa spans all SavedTerms and the Planner; TermGpa spans one Term.
- A FeeBreakdown belongs to one (Program, planned Credits, WaiverTier, FirstTerm) combination and produces one PaymentSchedule.
- A Retake of a Course replaces the earlier attempt with the same CourseCode in Cgpa and reduces tuition through the RetakeWaiver.

## Flagged ambiguities

- "semester" meant both the generic teaching period and the B.Pharm-specific Semester; the generic word is Term, the specific one is Semester (vs Trimester).
- "GPA" meant both the per-Term average and the cumulative one; use TermGpa and Cgpa.
- "registration fee" meant both the per-Term TermFee (Tk 6,500/9,750) and the one-time AdmissionFee (Tk 20,000); use those two words.
- "marks" vs "grade": percentage marks only exist in the grading-scale table; everything the Student enters is a LetterGrade.

@@@FILE docs/adr/0001-localstorage-only-state.md@@@
# 0001. SavedTerms live in browser localStorage only — no backend, no accounts

Status: accepted | Date: 2026-10-23

## Context

The app keeps a Student's SavedTerms across visits so Cgpa can span Terms. The alternatives considered: (a) a backend with accounts and a database, (b) browser localStorage, (c) import/export files only. The data is personal, low-volume (a few KB per Student), needed on one device at a time, and contains no secrets. A backend would add auth, hosting state, privacy obligations and two more modules to the swarm plan, for a calculator whose entire domain is pure functions. Alternatives (b) and (c) were weighed against cross-device sync, which no stated user needs.

## Decision

All Student state (SavedTerms, selected Program, WaiverTier, FirstTerm flag) persists in browser localStorage under one versioned key. The domain stays pure: it receives state and returns results; it never reads storage itself. There is no server-side state anywhere in the app.

## Consequences

Easier: the deployed app is static output on Vercel with zero runtime cost and zero user data held; every domain function stays trivially testable at seam S1; the swarm needs no database, auth or API tasks, which keeps ownership disjoint. Harder: no cross-device sync and clearing browser data erases SavedTerms — the UI must say this plainly. A future backend must slot in behind the same state shape (the versioned storage key is the migration seam), so the stored JSON schema may not diverge from the domain types. Do not reverse this casually: introducing server state changes the deployment model, the privacy surface and the whole test strategy at once.
@@@END@@@

# Code review (swarm edition)

Adapted from mattpocock/skills `code-review` (MIT). See `../NOTICE.md`.

A change can follow every convention and build the wrong thing (Standards pass, Spec fail), or build exactly the right thing in violation of conventions (Spec pass, Standards fail). Keep the axes **separate**: review once per axis, never merge or re-rank findings across them.

## 1. Pin the fixed point
Self-review: `git merge-base origin/<base branch> HEAD`. Review-mode task: the fixed point named in the task file. Capture the diff once: `git diff <fixed-point>...HEAD` and `git log <fixed-point>..HEAD --oneline`. An empty or unresolvable diff is an error; stop and report.

## 2. Pass one: Spec
Sources, in order: your task file's Objective and Acceptance criteria, then the user stories it cites from `.jules/spec.md`. Report, quoting the source line for each:
- requirements missing or partial
- behaviour in the diff nobody asked for (scope creep)
- requirements that look implemented but whose implementation looks wrong
Read this pass against the diff only, as if you had not written it.

## 3. Pass two: Standards
Sources: AGENTS.md sections 3, 4, 6; repo docs such as CONTRIBUTING or coding standards; the glossary (names match it); ADRs in the touched area; then the smell baseline below. Documented standards are hard findings. Baseline smells are always judgement calls ("possible Feature Envy"), and a documented repo standard overrides them. Skip anything the linter or type checker already enforces.

Smell baseline (smell: fix):
- Mysterious Name: rename; if no honest name comes, the design is murky.
- Duplicated Code: extract the shared shape.
- Feature Envy: move the method onto the data it uses.
- Data Clumps: bundle the travelling fields into a type.
- Primitive Obsession: give the domain concept its own small type.
- Repeated Switches: one polymorphic site or one shared map.
- Shotgun Surgery: gather what changes together into one module.
- Divergent Change: split a module that changes for unrelated reasons.
- Speculative Generality: delete abstraction the spec does not need.
- Message Chains: hide the walk behind one method.
- Middle Man: call the real target directly.
- Refused Bequest: replace inheritance with composition.

Slop checklist (each is a hard finding): leftover debug output or `[DEBUG-` tags; bare TODO/FIXME; stub language ("implement me", "rest of the code"); commented-out code; suppressed lint or type errors; skipped, focused or assertion-free tests; tautological or call-count-only tests; mocks of your own modules; a comment that restates the code beside it; a helper, parameter or option used by nothing; error handling that swallows. Run `python .jules/tools/slop_guard.py` to catch the mechanical ones.

## 4. Act on findings (self-review)
- Fix every Spec gap and every hard Standards finding inside your owned paths.
- Fix judgement-call smells when the fix is small and safe. Otherwise list them in the report as "left" with the reason.
- A finding in code you do not own becomes a request (`.jules/requests/<ID>-<slug>.md`).
- Re-run the verify command and `slop_guard.py` after the fixes. Then write the report.

## 5. Review-mode task output

# Codebase design (swarm edition)

Adapted from mattpocock/skills `codebase-design` (MIT). See `../NOTICE.md`.

Use these words exactly. Consistent language is the point; do not substitute "component", "service", "API" or "boundary".

- **Module**: anything with an interface and an implementation, at any scale (function, class, package, slice).
- **Interface**: everything a caller must know: type signature, invariants, ordering, error modes, configuration, performance.
- **Seam**: the place where a module's interface lives and behaviour can change without editing in place.
- **Adapter**: a concrete thing satisfying an interface at a seam.
- **Depth**: behaviour a caller can exercise per unit of interface learned. **Deep** = lots of behaviour behind a small interface. **Shallow** = interface nearly as complex as the implementation.
- **Leverage**: what callers gain from depth. **Locality**: what maintainers gain; change, bugs and verification concentrate in one place.

## Principles
- Depth is a property of the interface, not the implementation. A deep module may be built from small internal parts that are not part of its interface.
- **Deletion test**: imagine deleting the module. Complexity vanishes: it was a pass-through. Complexity reappears across N callers: it earns its keep.
- The interface is the test surface. If you need to test past it, the module is the wrong shape.
- One adapter is a hypothetical seam; two adapters is a real one. Add a seam only where something actually varies.

## Designing for testability
1. Accept dependencies; do not create them inside.
2. Return results; avoid hidden side effects.
3. Keep the surface small: fewer methods and parameters mean fewer tests and simpler setup.

## In this swarm
- The directory you own is a module. Its frozen contract in `contracts/**` is its interface. Keep both small and keep the behaviour behind them.
- Frozen contracts make disjoint ownership possible: that is why interfaces are decided before the wave starts, and why you never edit them.
- When designing inside your paths, prefer deepening an existing module over adding a new shallow one.

# Test-driven development (swarm edition)

Adapted from mattpocock/skills `tdd` (MIT). See `../NOTICE.md`.

A test is worth keeping when it describes behaviour through a public interface and survives any refactor that keeps behaviour. Everything below serves that.

## Seams: where tests live
A **seam** is the public boundary where you observe behaviour without reaching inside. Your task file lists them under "Seams under test" (ids S1, S2... from `.jules/spec.md`). Test at those seams only.
- Need a test the listed seams cannot express? Use the public interface of the module you own, record it in your report under "Seam added", and carry on. Never test internals.
- Only internals are reachable? Treat that as a design finding. Write it in the report; keep the code, skip the internal test.

## The loop (one slice at a time)
1. **Red.** Write one test for one behaviour at one seam. Run it. Confirm it fails for the right reason (the behaviour is missing, not a typo). Keep that failing line for your report.
2. **Green.** Write only enough code to pass. Speculative features wait for their own test.
3. **Next slice.** The last cycle teaches you what the next test should be. One test, one implementation, repeat. Each test is a tracer bullet.
4. Refactoring belongs to your self-review (skill `code-review`), run once all slices are green.

Writing every test first and every implementation after (horizontal slicing) tests imagined behaviour and locks in structure before you understand it. Stay vertical.

## Refactor and migration tasks
Pin current behaviour first: write characterization tests at the seam that pass on the untouched code (green-first), commit them, then change the code. The tests prove equivalence.

## Good and bad tests
Good: reads like a specification, calls the public interface, one logical assertion, describes WHAT.
```
test("user can checkout with valid cart", async () => {
  const cart = createCart();
  cart.add(product);
  const result = await checkout(cart, paymentMethod);
  expect(result.status).toBe("confirmed");
});
```
Implementation-coupled (rewrite): mocks internal collaborators, asserts call counts or order, reads the database to verify what the interface could confirm, breaks on refactor with unchanged behaviour.
```
// verify through the interface
const user = await createUser({ name: "Alice" });
expect((await getUser(user.id)).name).toBe("Alice");
```
Tautological (rewrite): the expected value is computed the way the code computes it, so the test passes by construction. Expected values come from an independent source: a literal, a worked example, the spec.
```
expect(calculateTotal([{ price: 10 }, { price: 5 }])).toBe(15);
```

## Mocking
Mock at system boundaries: external APIs, time and randomness, the filesystem when needed, the database only when a test database is unavailable. Your own modules and collaborators stay real.
- Pass dependencies in (`processPayment(order, paymentClient)`); constructing a client inside the function makes it untestable.
- Prefer one function per external operation (`api.getUser`, `api.createOrder`) over one generic `fetch(endpoint, options)`. Each mock then returns one shape with no branching in test setup.

## Evidence for the report
List: seams used, first-red output per slice (one line each), final green run. The reviewer reads this to confirm tests came first.

# Running this Jules swarm

You do not write code or plans. You copy, paste, merge and click. Everything runs through one command:

```
python .jules/tools/swarm.py <command>
```

| Command | What it does |
|---|---|
| `doctor` | Checks the pack, the plan, CI and tools. Run it before the first launch and after any change. |
| `launch` | Prints the launcher prompts for the next ready wave. Paste one prompt per Jules session. |
| `status` | Shows which tasks are merged, what is waiting, open requests, and the next step. |
| `guard` | Runs the ownership and slop checks on your current branch, the same ones CI runs. |
| `replan` | Writes `replan.md` (reports, requests, plan, history) to paste to the architect. |

Options: `launch --wave N`, `launch --task T03` (restart one task). Settings live in `.jules/swarm.json`.

## The loop
1. `doctor`. Fix anything marked FAIL. Commit and push (including the integration branch if the plan uses one).
2. In Jules settings, turn on plan auto-approval and CI Auto-Fixer (the architect's checklist lists the rest).
3. `launch`. Start one Jules session per prompt, all from the base branch named in the prompt.
4. When PRs open, wait for CI. Merge every PR of the wave (order does not matter), then `git pull`.
5. `status`. It names the next step. Repeat from step 3 until all waves are merged.
6. After the review task: `replan`, then paste `replan.md` to the architect after the word REPLAN. The architect writes a fix wave.
7. Merge the integration branch to the default branch once, after the last review.

## When something looks wrong
| Symptom | What to do |
|---|---|
| `doctor` says FAIL | Fix the named file; rerun. |
| A PR fails `ownership-guard` | The agent edited a file it does not own. Ask Jules to revert those files, or merge nothing and `replan`. |
| A PR fails `slop-guard` | The PR adds a TODO, stub, skipped test, suppressed error or similar. CI Auto-Fixer usually fixes it; otherwise comment the log line back to the session. |
| A task says PARTIAL | The agent hit a gap. Read its report; `replan` before launching dependent waves. |
| `.jules/requests/` has files | An agent needs a change in a file it does not own. `replan` resolves them. |
| A session stalls | `launch --task T0X` and start a fresh session for that task. |
| `slop_guard` cannot find the base | `git fetch origin <base branch>`, then rerun. |

Files you never edit by hand: `AGENTS.md`, `GLOSSARY.md`, `docs/adr/`, `.jules/` (except reading it), `.agents/skills/`. Change them through the architect with `REPLAN`.

#!/usr/bin/env python3
"""Ownership guard. Copy to .jules/tools/ownership_guard.py in the target repo.

Fails a PR that changes files outside its task's owned paths.
Task ID is read from PR_TITLE, then PR_HEAD_REF (pattern T01, T002...).
Env: PR_TITLE, PR_HEAD_REF, BASE_REF (default origin/main), GUARD_STRICT=1 to fail
when no task ID is found. Stdlib only.
"""
import csv
import json
import os
import re
import subprocess
import sys

TASKS = ".jules/tasks.csv"
RESERVED = ["AGENTS.md", ".jules/tasks/**", ".jules/tasks.csv", ".jules/ownership.csv",
            ".jules/skills.csv", ".jules/deps.csv", ".jules/tools/**", ".jules/plan.md",
            ".agents/skills/**", "GLOSSARY.md", "CONTEXT.md", ".jules/spec.md", ".jules/swarm.json", ".jules/README.md", "docs/adr/**"]


def to_regex(glob):
    glob = glob.replace("\\", "/").strip()
    while glob.startswith("./"):
        glob = glob[2:]
    if glob.endswith("/"):
        glob += "**"
    i, out = 0, ""
    while i < len(glob):
        c = glob[i]
        if glob.startswith("**/", i):
            out += "(?:.*/)?"
            i += 3
        elif glob.startswith("/**", i) and i + 3 == len(glob):
            out += "(?:/.*)?"
            i += 3
        elif glob.startswith("**", i):
            out += ".*"
            i += 2
        elif c == "*":
            out += "[^/]*"
            i += 1
        elif c == "?":
            out += "[^/]"
            i += 1
        else:
            out += re.escape(c)
            i += 1
    return re.compile("^" + out + "$")


def matches(path, globs):
    return any(to_regex(g).match(path) for g in globs)


def split(v):
    return [x.strip() for x in (v or "").split(";") if x.strip()]


def resolve_base(explicit=None):
    """Pick the base ref: --base, BASE_REF, .jules/swarm.json base_branch, origin/HEAD, origin/main, origin/master."""
    def ok(ref):
        return bool(ref) and subprocess.run(["git", "rev-parse", "--verify", "--quiet", ref],
                                            capture_output=True).returncode == 0
    cands = [explicit, os.environ.get("BASE_REF")]
    try:
        top = subprocess.run(["git", "rev-parse", "--show-toplevel"], capture_output=True, text=True, check=True).stdout.strip()
        with open(os.path.join(top, ".jules", "swarm.json"), encoding="utf-8") as f:
            b = (json.load(f).get("base_branch") or "").strip()
        if b:
            cands += [f"origin/{b}", b]
    except (OSError, ValueError, subprocess.CalledProcessError):
        pass
    cands += ["origin/HEAD", "origin/main", "origin/master"]
    for c in cands:
        if ok(c):
            return c
    return explicit or os.environ.get("BASE_REF") or "origin/main"


def changed_files():
    base = resolve_base()
    out = subprocess.run(["git", "diff", "--name-only", f"{base}...HEAD"],
                         capture_output=True, text=True, check=True).stdout
    return [l.strip() for l in out.splitlines() if l.strip()]


def main():
    if not os.path.exists(TASKS):
        print("guard: no .jules/tasks.csv, skipping")
        return 0
    with open(TASKS, newline="", encoding="utf-8") as f:
        tasks = {r["task_id"].strip(): r for r in csv.DictReader(f)
                 if r.get("task_id") and not r["task_id"].startswith("#")}
    files = changed_files()
    if not files:
        print("guard: no changes")
        return 0
    text = f"{os.environ.get('PR_TITLE', '')} {os.environ.get('PR_HEAD_REF', '')}"
    m = re.search(r"\bT\d{2,3}\b", text, re.I) or re.search(r"(?<![A-Za-z0-9])T\d{2,3}(?![0-9])", text, re.I)
    tid = m.group(0).upper() if m else None

    def allowed_for(t):
        return split(tasks[t]["owns"]) + [f".jules/reports/{t}*.md", f".jules/requests/{t}-*.md"]

    if tid and tid in tasks:
        allowed = allowed_for(tid)
        bad = [p for p in files if not matches(p, allowed)]
        reserved = [p for p in bad if matches(p, RESERVED)]
        if bad:
            print(f"guard FAIL: {tid} changed files outside its ownership:")
            for p in bad:
                print(f"  - {p}" + ("  [RESERVED]" if p in reserved else ""))
            print("Fix: revert these edits. If needed, write .jules/requests/"
                  f"{tid}-<slug>.md describing the change for the owner.")
            return 1
        print(f"guard OK: {tid} touched {len(files)} file(s), all owned")
        return 0

    cands = [t for t in tasks if all(matches(p, allowed_for(t)) for p in files)]
    if cands:
        print(f"guard OK (inferred task {cands[0]})")
        return 0
    msg = "guard: no task ID in PR title/branch and no single task owns all changed files"
    if os.environ.get("GUARD_STRICT") == "1":
        print("FAIL " + msg)
        return 1
    print("NOTICE " + msg + " (set GUARD_STRICT=1 to enforce)")
    return 0


if __name__ == "__main__":
    sys.exit(main())

#!/usr/bin/env python3
"""Slop guard. Copy to .jules/tools/slop_guard.py in the target repo.

Scans only the lines a PR ADDS (git diff -U0 BASE...HEAD) for patterns that mark

the run; heuristic rules are WARNs (they fail only with --strict).

  --base / BASE_REF   base ref; else .jules/swarm.json base_branch, origin/HEAD, origin/main, origin/master
  --strict            WARNs fail too
  --json              machine-readable output
Escape hatch: append `slop-ok: <reason of 8+ chars>` on the same line. The finding is
reported as NOTICE and does not fail. Reviewers read NOTICEs.
Exit 1 if any ERROR. Stdlib only.
"""

import json
import os
import re
import subprocess
import sys

SKIP_TEST = re.compile(r"\b(describe|it|test)\.(skip|only|todo)\b|\b(xit|xdescribe|xtest|fit|fdescribe|ftest)\s*\("

EMPTY_CATCH = re.compile(r"catch\s*(\([^)]*\))?\s*\{\s*(//[^\n]*)?\}|except[^:\n]*:\s*pass\b|\.catch\(\s*\(\s*\)\s*=>\s*\{\s*\}\s*\)")
DEBUG_STMT = re.compile(r"^\s*debugger;?\s*$|\bpdb\.set_trace\(|\bbreakpoint\(\)|\bbinding\.pry\b")
DEBUG_TAG = re.compile(r"\[DEBUG-[0-9a-f]{2,}\]", re.I)
TAUTOLOGY = re.compile(r"expect\(\s*(?P<a>.+?)\s*\)\.(?:toBe|toEqual|toStrictEqual)\(\s*(?P=a)\s*\)"
                       r"|\bassert\s+(?P<b>[\w.()\[\], ]+?)\s*==\s*(?P=b)\s*$|\bassert\s+(?:True|1)\s*$"
                       r"|assertTrue\(\s*true\s*\)")
ANY_TYPE = re.compile(r":\s*any\b|\bas any\b|<any>|\bas unknown as\b")
CONSOLE = re.compile(r"\bconsole\.(log|debug|trace)\(|^\s*print\(|\bfmt\.Println\(|\bdbg!\(|\bSystem\.out\.println\(")
COMMENTED_CODE = re.compile(r"^\s*(//|#)\s*(const|let|var|def|class|import|from|return|if|for|while|function|await|export)\b.*[;{(:,]\s*$")
INTERNAL_MOCK = re.compile(r"\b(jest|vi)\.mock\(\s*['\"]\.{1,2}/|\bmock\.patch\(\s*['\"][\w.]+['\"]|\bsinon\.stub\(\s*[\w.]+,")
CALL_ASSERT = re.compile(r"toHaveBeenCalled(Times|With)?\(|assert_called|\.calledWith\(|verify\([\w.]+\)\.")
SNAPSHOT = re.compile(r"toMatch(Inline)?Snapshot\(")
TEST_DEF = re.compile(r"^\s*(it|test)\s*\(|^\s*def test_|^\s*func Test\w+\(|^\s*#\[test\]|@Test\b")
ASSERT_TOK = re.compile(r"\bexpect\s*\(|\bassert|\.should\b|\bt\.(Error|Errorf|Fatal|Fatalf|Fail)\b|\brequire\.|\bverify\(|\.toThrow|\bpytest\.raises|\bassertThat\b|\bEXPECT_|\bASSERT_")

ERR, WARN = "ERROR", "WARN"


def resolve_base(explicit=None):
    """Pick the base ref: --base, BASE_REF, .jules/swarm.json base_branch, origin/HEAD, origin/main, origin/master."""
    def ok(ref):
        return bool(ref) and subprocess.run(["git", "rev-parse", "--verify", "--quiet", ref],
                                            capture_output=True).returncode == 0
    cands = [explicit, os.environ.get("BASE_REF")]
    try:
        top = subprocess.run(["git", "rev-parse", "--show-toplevel"], capture_output=True, text=True, check=True).stdout.strip()
        with open(os.path.join(top, ".jules", "swarm.json"), encoding="utf-8") as f:
            b = (json.load(f).get("base_branch") or "").strip()
        if b:
            cands += [f"origin/{b}", b]
    except (OSError, ValueError, subprocess.CalledProcessError):
        pass
    cands += ["origin/HEAD", "origin/main", "origin/master"]
    for c in cands:
        if ok(c):
            return c
    return explicit or os.environ.get("BASE_REF") or "origin/main"


def run(cmd):
    return subprocess.run(cmd, capture_output=True, text=True, check=True).stdout


def added_lines(base):
    """Yield (path, lineno, text) for lines added by the PR."""
    out = run(["git", "diff", "-U0", "--no-color", "--diff-filter=AMR", f"{base}...HEAD"])
    path, ln = None, 0
    for raw in out.splitlines():
        if raw.startswith("+++ b/"):
            path = raw[6:]
        elif raw.startswith("+++ "):
            path = None
        elif raw.startswith("@@"):
            m = re.search(r"\+(\d+)", raw)
            ln = int(m.group(1)) if m else 0
        elif raw.startswith("+") and not raw.startswith("+++"):
            if path:
                yield path, ln, raw[1:]
            ln += 1


def skip(path):
    return path.startswith(SKIP_PREFIXES) or path.endswith(SKIP_SUFFIXES)


def scan(base):
    findings, by_file = [], {}
    for path, ln, text in added_lines(base):
        if skip(path):
            continue
        by_file.setdefault(path, []).append((ln, text))
    for path, lines in by_file.items():
        is_code = path.endswith(CODE_EXT)
        is_test = bool(TEST_PATH.search(path))
        prev = None

        def add(rule, sev, ln, text, msg):
            ok = OK_MARK.search(text)
            findings.append({"rule": rule, "severity": "NOTICE" if ok else sev, "file": path, "line": ln,
                             "message": msg + (f" (slop-ok: {ok.group(1).strip()})" if ok else ""),
                             "text": text.strip()[:140]})

        for ln, text in lines:
            if DEBUG_TAG.search(text):
                add("S01", ERR, ln, text, "debug tag left behind; remove the instrumentation")
            if is_code and TODO.search(text):
                add("S02", ERR, ln, text, "bare TODO/FIXME; finish it, or write TODO(T07-slug) pointing at a filed request")
            if is_code and (STUB.search(text) or STUB_CALLS.search(text)):
                add("S03", ERR, ln, text, "stub or placeholder language; implement it or file a request")
            if is_test and SKIP_TEST.search(text):
                add("S04", ERR, ln, text, "skipped, focused or todo test; fix it, never disable it")
            if is_code and SUPPRESS_ERR.search(text):
                add("S05", ERR, ln, text, "blanket suppression of a lint or type error; fix the cause")
            elif is_code and SUPPRESS_WARN.search(text):
                add("W05", WARN, ln, text, "targeted suppression; confirm it carries a reason")
            if is_code and EMPTY_CATCH.search(text):
                add("S06", ERR, ln, text, "swallowed error; handle it or let it propagate")
            if is_code and prev and re.match(r"\s*except[^:\n]*:\s*$", prev[1]) and text.strip() == "pass":
                add("S06", ERR, ln, text, "swallowed error (except: pass); handle it or let it propagate")
            if is_code and DEBUG_STMT.search(text):
                add("S09", ERR, ln, text, "debugger statement left in code")
            if is_test and TAUTOLOGY.search(text):
                add("S08", ERR, ln, text, "tautological assertion; expected value must come from an independent source")
            if is_code and ANY_TYPE.search(text) and path.endswith((".ts", ".tsx")):
                add("W01", WARN, ln, text, "`any` erases type safety; model the type")
            if is_code and not is_test and CONSOLE.search(text):
                add("W03", WARN, ln, text, "debug-style output in source; use the project logger or remove it")
            if is_code and COMMENTED_CODE.search(text):
                add("W02", WARN, ln, text, "commented-out code; delete it (git remembers)")
            if is_test and INTERNAL_MOCK.search(text):
                add("W04", WARN, ln, text, "mock of an internal module; mock only system boundaries")
            if is_test and CALL_ASSERT.search(text):
                add("W06", WARN, ln, text, "asserts on calls, not behaviour; assert the observable result")
            if is_test and SNAPSHOT.search(text):
                add("W07", WARN, ln, text, "snapshot derived from the implementation; assert the specific behaviour")
            prev = (ln, text)

        if is_test and path.endswith(CODE_EXT):
            try:
                with open(path, encoding="utf-8", errors="replace") as f:
                    body = f.read()
            except OSError:
                continue
            if any(TEST_DEF.search(t) for _, t in lines) and not ASSERT_TOK.search(body):
                first = next(ln for ln, t in lines if TEST_DEF.search(t))
                findings.append({"rule": "S07", "severity": ERR, "file": path, "line": first,
                                 "message": "test file defines tests but contains no assertion", "text": ""})
    return findings


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--base", default=None)
    ap.add_argument("--strict", action="store_true")
    ap.add_argument("--json", action="store_true")
    a = ap.parse_args()
    a.base = resolve_base(a.base)
    try:
        findings = scan(a.base)
    except subprocess.CalledProcessError as e:
        print(f"slop_guard: git failed ({e.stderr.strip() or e}). Is BASE_REF '{a.base}' fetched?")
        return 2
    gha = os.environ.get("GITHUB_ACTIONS") == "true"
    errs = [f for f in findings if f["severity"] == ERR]
    warns = [f for f in findings if f["severity"] == WARN]
    notes = [f for f in findings if f["severity"] == "NOTICE"]
    if a.json:
        print(json.dumps(findings, indent=2))
    else:
        for f in sorted(findings, key=lambda f: (f["severity"] != ERR, f["file"], f["line"])):
            tag = f"[{f['rule']}] {f['file']}:{f['line']}: {f['message']}"
            if gha and f["severity"] in (ERR, WARN):
                lvl = "error" if f["severity"] == ERR else "warning"
                print(f"::{lvl} file={f['file']},line={f['line']}::[{f['rule']}] {f['message']}")
            print(f"{f['severity']:6} {tag}" + (f"\n         > {f['text']}" if f["text"] else ""))
        print(f"slop_guard: {len(errs)} error(s), {len(warns)} warning(s), {len(notes)} notice(s) in added lines vs {a.base}")
    return 1 if errs or (a.strict and warns) else 0


if __name__ == "__main__":
    sys.exit(main())

#!/usr/bin/env python3
"""swarm: the one command for running a Jules swarm. Copy to .jules/tools/swarm.py.

  python .jules/tools/swarm.py doctor            preflight before launching (pack, plan, CI, tools)
  python .jules/tools/swarm.py status            which tasks merged, what is next, what needs attention
  python .jules/tools/swarm.py launch [--wave N] [--task T03]   launcher prompts for the next wave
  python .jules/tools/swarm.py replan [--out F]  bundle reports, requests and plan for the architect
  python .jules/tools/swarm.py guard             run slop_guard and ownership_guard locally

Settings live in .jules/swarm.json (repo, base_branch, glossary_file, max_concurrent, plan_concurrent).
Global option: --root PATH (default: the git top-level, else the current directory).
Needs Python 3.9+ and git. Stdlib only.
"""

TID = re.compile(r"\bT\d{2,3}\b")
PLACEHOLDER = re.compile(r"\{\{[^}]*\}\}")
OK, WARN, BAD = "OK  ", "WARN", "FAIL"


def git(root, *args):
    r = subprocess.run(["git", "-C", root, *args], capture_output=True, text=True)
    return r.returncode, r.stdout.strip(), r.stderr.strip()


def find_root(arg):
    if arg:
        return os.path.abspath(arg)
    r = subprocess.run(["git", "rev-parse", "--show-toplevel"], capture_output=True, text=True)
    return r.stdout.strip() if r.returncode == 0 else os.getcwd()


def load_cfg(root):
    try:
        with open(os.path.join(root, ".jules", "swarm.json"), encoding="utf-8") as f:
            return json.load(f)
    except (OSError, ValueError):
        return {}


def read_csv(path):
    if not os.path.exists(path):
        return []
    with open(path, newline="", encoding="utf-8") as f:
        return [r for r in csv.DictReader(f) if r.get("task_id") or r.get("skill")]


def split(v):
    return [x.strip() for x in (v or "").split(";") if x.strip()]


def tasks_of(root):
    rows = [r for r in read_csv(os.path.join(root, ".jules", "tasks.csv"))
            if r.get("task_id") and not r["task_id"].startswith("#")]
    return {r["task_id"].strip(): r for r in rows}


def base_ref(root, cfg):
    b = (cfg.get("base_branch") or "").strip()
    cands = [f"origin/{b}", b] if b else []
    cands += ["origin/HEAD", "origin/main", "origin/master", "HEAD"]
    for c in cands:
        if c and git(root, "rev-parse", "--verify", "--quiet", c)[0] == 0:
            return c
    return "HEAD"


def merged_tasks(root, cfg, tasks):
    """Task IDs found in the history of the base branch: PR titles '[T03] ...' or branches 'jules/T03-...'."""
    ref = base_ref(root, cfg)
    code, out, _ = git(root, "log", ref, "--format=%s%n%b%x1e")
    found = set()
    if code == 0:
        for entry in out.split("\x1e"):
            lines = entry.strip().splitlines()
            subj = lines[0] if lines else ""
            m = re.match(r"\s*\[(T\d{2,3})\b", subj, re.I)
            if m:
                found.add(m.group(1).upper())
            for b in re.findall(r"jules/(T\d{2,3})-", entry, re.I):
                found.add(b.upper())
    return {t for t in found if t in tasks}, ref


def report_status(root, tid):
    p = os.path.join(root, ".jules", "reports", f"{tid}.md")
    if not os.path.exists(p):
        return None
    with open(p, encoding="utf-8", errors="replace") as f:
        for line in f:
            m = re.match(r"\s*Status:\s*(\w+)", line, re.I)
            if m:
                return m.group(1).upper()
    return "UNKNOWN"


def open_requests(root):
    return sorted(os.path.basename(p) for p in glob.glob(os.path.join(root, ".jules", "requests", "*.md")))


def waves_of(tasks):
    w = {}
    for tid, r in tasks.items():
        w.setdefault(int(r["wave"]), []).append(tid)
    return {k: sorted(v) for k, v in sorted(w.items())}


def compute_status(root, cfg):
    tasks = tasks_of(root)
    merged, ref = merged_tasks(root, cfg, tasks)
    waves = waves_of(tasks)
    current = next((w for w, ids in waves.items() if not all(t in merged for t in ids)), None)
    return tasks, merged, ref, waves, current


# ------------------------------------------------------------------ status
def cmd_status(a):
    root = find_root(a.root)
    cfg = load_cfg(root)
    tasks, merged, ref, waves, current = compute_status(root, cfg)
    if not tasks:
        print("status: no .jules/tasks.csv found. Run this at the repo root of a swarm pack.")
        return 2
    print(f"SWARM STATUS  base: {ref}  ({len(merged)}/{len(tasks)} tasks merged)\n")
    reqs = open_requests(root)
    partial = []
    for w, ids in waves.items():
        mark = "done" if all(t in merged for t in ids) else ("current" if w == current else "later")
        print(f"Wave {w} [{mark}]")
        for t in ids:
            rs = report_status(root, t)
            state = "MERGED" if t in merged else "pending"
            extra = ""
            if t in merged and rs is None:
                extra = "  (merged, no report found: git pull?)"
            if rs == "PARTIAL":
                partial.append(t)
                extra = "  PARTIAL"
            print(f"  {t:5} {state:8} {tasks[t]['title'].strip()[:48]}{extra}")
    print()
    if reqs:
        print(f"Open requests ({len(reqs)}): " + ", ".join(reqs[:6]) + (" ..." if len(reqs) > 6 else ""))
    if partial:
        print("PARTIAL tasks: " + ", ".join(partial))
    print()
    if current is None:
        review = [t for t, r in tasks.items() if r.get("mode", "").strip() == "review"]
        if review and any(report_status(root, t) for t in review):
            print("NEXT: all waves merged and a review report exists. Run `swarm.py replan` and send it to the architect.")
        else:
            print("NEXT: all waves merged. Run the verify command on the base branch, then `swarm.py replan` if requests or PARTIAL tasks remain.")
        return 0
    pending = [t for t in waves[current] if t not in merged]
    done_in_wave = [t for t in waves[current] if t in merged]
    if not done_in_wave:
        attention = " Resolve open requests or PARTIAL tasks with REPLAN first." if (reqs or partial) else ""
        print(f"NEXT: wave {current} is ready. Run `swarm.py launch` ({len(pending)} agent(s)).{attention}")
    else:
        print(f"NEXT: waiting on {', '.join(pending)} (wave {current}). Merge their PRs, `git pull`, rerun `swarm.py status`.")
        print(f"      To restart one task: `swarm.py launch --task {pending[0]}`")
    return 0


# ------------------------------------------------------------------ launch
def cmd_launch(a):
    root = find_root(a.root)
    cfg = load_cfg(root)
    tasks, merged, ref, waves, current = compute_status(root, cfg)
    if not tasks:
        print("launch: no .jules/tasks.csv found")
        return 2
    cmd = [sys.executable, os.path.join(TOOLS, "render_launch_sheet.py"), "--root", root]
    if a.task:
        for t in a.task:
            cmd += ["--task", t]
    else:
        wave = a.wave if a.wave is not None else current
        if wave is None:
            print("launch: every wave is already merged. Use --wave N to print one anyway.")
            return 0
        if not a.force:
            blockers = [t for w, ids in waves.items() if w < wave for t in ids if t not in merged]
            if blockers:
                print(f"launch: wave {wave} is not ready. Unmerged earlier tasks: {', '.join(blockers)}")
                print("        Merge those PRs (CI green), `git pull`, or pass --force.")
                return 1
        cmd += ["--wave", str(wave)]
    return subprocess.run(cmd).returncode

def cmd_replan(a):
    root = find_root(a.root)
    cfg = load_cfg(root)
    tasks, merged, ref, waves, current = compute_status(root, cfg)
    out = a.out or os.path.join(root, "replan.md")
    if not a.out:  # keep the default bundle out of commits without touching the tracked .gitignore
        rc, gdir, _ = git(root, "rev-parse", "--git-path", "info/exclude")
        if rc == 0:
            ex = gdir if os.path.isabs(gdir) else os.path.join(root, gdir)
            try:
                os.makedirs(os.path.dirname(ex), exist_ok=True)
                have = open(ex, encoding="utf-8").read() if os.path.exists(ex) else ""
                if "/replan.md" not in have.split():
                    with open(ex, "a", encoding="utf-8") as f:
                        f.write(("" if have.endswith("\n") or not have else "\n") + "/replan.md\n")
            except OSError:
                pass
    parts = ["# REPLAN\n", f"Project: {cfg.get('project', '')}  Base branch: {ref}\n"]

    def add_file(title, rel, fence=""):
        p = os.path.join(root, rel)
        if os.path.exists(p):
            with open(p, encoding="utf-8", errors="replace") as f:
                body = f.read().rstrip()
            parts.append(f"\n## {title}\n" + (f"```{fence}\n{body}\n```\n" if fence is not None else body + "\n"))

    import io
    import contextlib
    buf = io.StringIO()
    with contextlib.redirect_stdout(buf):
        cmd_status(argparse.Namespace(root=root))
    parts.append("\n## Status\n```\n" + buf.getvalue().rstrip() + "\n```\n")
    add_file("plan.md", ".jules/plan.md", None)
    add_file("tasks.csv", ".jules/tasks.csv", "csv")
    for p in sorted(glob.glob(os.path.join(root, ".jules", "reports", "*.md"))):
        add_file(f"Report {os.path.basename(p)[:-3]}", os.path.relpath(p, root), None)
    for p in sorted(glob.glob(os.path.join(root, ".jules", "requests", "*.md"))):
        add_file(f"Request {os.path.basename(p)}", os.path.relpath(p, root), None)
    _, log, _ = git(root, "log", ref, "--oneline", "-n", "40")
    parts.append("\n## Merged history\n```\n" + log + "\n```\n")
    text = "".join(parts)
    with open(out, "w", encoding="utf-8") as f:
        f.write(text)
    kb = len(text.encode("utf-8")) / 1024
    print(f"replan: wrote {out} ({kb:.0f} KB). Paste it into the architect chat after the word REPLAN.")
    if kb > 80:
        print("replan: large bundle. Delete reports of tasks that finished DONE with nothing to flag before pasting.")
    return 0

def cmd_guard(a):
    root = find_root(a.root)
    cfg = load_cfg(root)
    ref = base_ref(root, cfg)
    env = dict(os.environ, BASE_REF=ref)
    _, branch, _ = git(root, "rev-parse", "--abbrev-ref", "HEAD")

    env.setdefault("PR_TITLE", subj)
    rc = 0
    for name in ("ownership_guard.py", "slop_guard.py"):
        p = os.path.join(TOOLS, name)
        if not os.path.exists(p):
            print(f"guard: {name} missing next to swarm.py")

            continue
        print(f"--- {name} (base {ref})")
        r = subprocess.run([sys.executable, p], cwd=root, env=env)
        rc = rc or r.returncode
    return rc

def cmd_doctor(a):
    root = find_root(a.root)
    cfg = load_cfg(root)
    errs = warns = 0

    def line(level, msg):
        nonlocal errs, warns
        errs += level == BAD
        warns += level == WARN
        print(f"{level} {msg}")

    print(f"SWARM DOCTOR  root: {root}\n")
    line(OK if sys.version_info >= (3, 9) else BAD, f"Python {sys.version.split()[0]} (needs 3.9+)")
    if git(root, "rev-parse", "--git-dir")[0] != 0:
        line(BAD, "not a git repository")
        return 1
    _, status, _ = git(root, "status", "--porcelain")
    line(OK if not status else WARN, "working tree clean" if not status else "uncommitted changes: commit and push the pack before launching")
    if not cfg:
        line(WARN, ".jules/swarm.json missing or invalid: tools fall back to defaults (base branch main)")
    else:
        bad = [k for k, v in cfg.items() if isinstance(v, str) and PLACEHOLDER.search(v)]
        line(BAD if bad else OK, f"swarm.json has unfilled values: {bad}" if bad else "swarm.json filled")
    base = (cfg.get("base_branch") or "").strip()
    if base:
        have_remote = git(root, "rev-parse", "--verify", "--quiet", f"origin/{base}")[0] == 0
        have_local = git(root, "rev-parse", "--verify", "--quiet", base)[0] == 0
        line(OK if have_remote else WARN,
             f"base branch '{base}' exists on origin" if have_remote else
             f"base branch '{base}' not on origin yet: `git push -u origin {base}` before launching" if have_local else
             f"base branch '{base}' not found: create it from the default branch")

    need = ["AGENTS.md", ".jules/tasks.csv", ".jules/ownership.csv", ".jules/skills.csv", ".jules/deps.csv",
            ".jules/plan.md", ".github/workflows/ci.yml", ".github/pull_request_template.md"]
    for rel in need:
        line(OK if os.path.exists(os.path.join(root, rel)) else BAD, rel)
    tools = ["ownership_guard.py", "slop_guard.py", "validate_plan.py", "render_launch_sheet.py"]
    for t in tools:
        line(OK if os.path.exists(os.path.join(TOOLS, t)) else BAD, f"tool {t}")

    skills = [r for r in read_csv(os.path.join(root, ".jules", "skills.csv")) if r.get("skill")]
    enabled = [r["skill"].strip() for r in skills if (r.get("enabled") or "").strip().lower() == "yes"]
    for s in enabled:
        ok = os.path.exists(os.path.join(root, ".agents", "skills", s, "SKILL.md"))
        line(OK if ok else BAD, f"skill {s}: .agents/skills/{s}/SKILL.md")
    notice = os.path.join(root, ".agents", "skills", "NOTICE.md")
    if enabled and os.path.exists(notice):
        with open(notice, encoding="utf-8") as f:
            if "paste verbatim here" in f.read():
                line(WARN, "NOTICE.md still asks for the upstream MIT licence text (paste it verbatim)")
    ci = os.path.join(root, ".github", "workflows", "ci.yml")
    if os.path.exists(ci):
        with open(ci, encoding="utf-8") as f:
            body = f.read()
        for job in ("ownership-guard", "slop-guard"):
            line(OK if job in body else WARN, f"CI job '{job}' present" if job in body else f"CI has no '{job}' job")
    for rel in ("AGENTS.md", ".github/workflows/ci.yml"):
        p = os.path.join(root, rel)
        if os.path.exists(p):
            with open(p, encoding="utf-8") as f:
                ph = sorted(set(PLACEHOLDER.findall(re.sub(r"(?s)<!--.*?-->|\$\{\{.*?\}\}", "", f.read()))))
            if ph:
                line(BAD, f"{rel} has unfilled placeholders {ph[:3]}")

    print("\n--- plan validation")
    vp = os.path.join(TOOLS, "validate_plan.py")
    if os.path.exists(vp):
        cmd = [sys.executable, vp, "--tasks", os.path.join(root, ".jules/tasks.csv"),
               "--ownership", os.path.join(root, ".jules/ownership.csv"), "--root", root,
               "--max-concurrent", str(cfg.get("max_concurrent", 7))]
        for flag, rel in (("--skills", ".jules/skills.csv"), ("--deps", ".jules/deps.csv")):
            if os.path.exists(os.path.join(root, rel)):

"""Validate a Jules swarm plan: collisions, wave logic, limits.

Usage:
  python validate_plan.py --tasks .jules/tasks.csv --ownership .jules/ownership.csv \
      [--skills .jules/skills.csv] [--deps .jules/deps.csv] [--root .] [--max-concurrent 7] \

Exit code 1 if any ERROR. Stdlib only.

import csv
import fnmatch
import glob
import os
import re
import sys
from functools import lru_cache

RESERVED = ["AGENTS.md", ".jules/tasks/**", ".jules/tasks.csv", ".jules/ownership.csv",
            ".jules/skills.csv", ".jules/deps.csv", ".jules/tools/**", ".jules/plan.md",
            ".agents/skills/**", "GLOSSARY.md", "CONTEXT.md", ".jules/spec.md", ".jules/swarm.json", ".jules/README.md"]
SOFT_RESERVED = ["docs/adr/**"]
MODES = {"foundation", "feature", "refactor", "integrate", "docs", "review", "fix", "amendment"}
CODE_MODES = {"foundation", "feature", "refactor", "fix", "integrate"}
TASK_COLS = ["task_id", "wave", "title", "slug", "model", "owns", "reads",
             "depends_on", "skills", "size", "mode"]
OWN_COLS = ["pattern", "class", "owner_task", "notes"]
DEP_COLS = ["ecosystem", "package", "version", "role", "status", "checked_on", "source"]
SKILL_COLS = ["skill", "source", "install_path", "applies_to", "enabled"]
DEP_STATUS = {"stable", "unverified"}
PRERELEASE = re.compile(r"(alpha|beta|rc|canary|nightly|next|dev|snapshot|preview|pre|exp|insiders?)", re.I)
RANGE_CHARS = re.compile(r"[\^~*<>=|xX]|latest")
CLASSES = {"hot", "contract", "generated"}
ID_RE = re.compile(r"^T\d{2,3}$")
WILD = set("*?[")


def split(v):
    return [x.strip() for x in (v or "").split(";") if x.strip()]


def norm(p):
    p = p.replace("\\", "/").strip()
    while p.startswith("./"):
        p = p[2:]
    if p.endswith("/"):
        p += "**"
    return p


def has_wild(s):
    return any(c in WILD for c in s)


def _prefix(s):
    for i, c in enumerate(s):
        if c in WILD:
            return s[:i]
    return s


def _suffix(s):
    for i in range(len(s) - 1, -1, -1):
        if s[i] in WILD:
            return s[i + 1:]
    return s


def seg_intersect(a, b):
    if not has_wild(a):
        return fnmatch.fnmatchcase(a, b)
    if not has_wild(b):
        return fnmatch.fnmatchcase(b, a)
    pa, pb, sa, sb = _prefix(a), _prefix(b), _suffix(a), _suffix(b)
    return (pa.startswith(pb) or pb.startswith(pa)) and (sa.endswith(sb) or sb.endswith(sa))


def globs_intersect(g1, g2):
    A = tuple(norm(g1).split("/"))
    B = tuple(norm(g2).split("/"))

    @lru_cache(maxsize=None)
    def go(i, j):
        if i == len(A) and j == len(B):
            return True
        if i == len(A):
            return all(s == "**" for s in B[j:])
        if j == len(B):
            return all(s == "**" for s in A[i:])
        a, b = A[i], B[j]
        if a == "**" or b == "**":
            return go(i + 1, j) or go(i, j + 1)
        return seg_intersect(a, b) and go(i + 1, j + 1)

    return go(0, 0)


def any_intersect(list_a, list_b):
    for x in list_a:
        for y in list_b:
            if globs_intersect(x, y):
                return x, y
    return None


def read_csv(path):
    if not os.path.exists(path):
        return None
    with open(path, newline="", encoding="utf-8") as f:
        rows = []
        for r in csv.DictReader(f):
            first = (list(r.values())[0] or "").strip()
            if first and not first.startswith("#"):
                rows.append(r)
    return rows


def check_deps(path, E, W, N):
    rows = read_csv(path) or []
    if not rows:
        W("deps.csv has no rows. Fine only if the plan installs no packages.")
        return
    miss = [c for c in DEP_COLS if c not in rows[0]]
    if miss:
        E(f"deps.csv missing columns {miss}")
        return
    seen = set()
    for r in rows:
        eco, pkg = r["ecosystem"].strip().lower(), r["package"].strip()
        ver, st = r["version"].strip(), r["status"].strip().lower()
        key = (eco, pkg)
        tag = f"dep {eco}:{pkg}"
        if key in seen:
            E(f"{tag}: duplicate row")
        seen.add(key)
        if st not in DEP_STATUS:
            E(f"{tag}: status '{st}' must be one of {sorted(DEP_STATUS)} (deprecated packages never go in the plan; "
              "record them in notes as 'replaces')")
        if not ver:
            E(f"{tag}: version is empty")
            continue
        if RANGE_CHARS.search(ver):
            E(f"{tag}: version '{ver}' is a range or tag. Pin an exact stable version.")
        elif PRERELEASE.search(ver):
            E(f"{tag}: version '{ver}' looks like a pre-release. Use the latest stable.")
        if st == "unverified":
            W(f"{tag}: UNVERIFIED. Run scripts/verify_deps.py or research it before emitting.")
        elif not r["checked_on"].strip() or not r["source"].strip():
            E(f"{tag}: stable rows need checked_on (date) and source (URL or registry)")
    N(f"deps.csv: {len(rows)} package(s) checked for pinning and status")


def parse_spec(path):
    with open(path, encoding="utf-8") as f:
        text = f.read()
    seams = set(re.findall(r"(?m)^\s*(?:[-*]\s*)?\**(S\d+)\**\s*[:\u2014-]", text))
    stories = set(re.findall(r"(?m)^\s*(?:\d+\.|[-*])\s*\**(U\d+)\**\s*[:\u2014-]", text))
    return seams, stories


def section(text, heading):
    m = re.search(r"(?ms)^##\s+" + re.escape(heading) + r"\s*$(.*?)(?=^##\s|\Z)", text)
    return m.group(1) if m else None


def check_quality_kit(by_id, known_enabled, E, W, N, has_seams_col, spec_seams):
    kit = "tdd" in known_enabled
    modes = {t["mode"].strip() for t in by_id.values()}
    for tid, t in by_id.items():
        mode = t["mode"].strip()
        if mode and mode not in MODES:
            W(f"{tid}: mode '{mode}' is not one of {sorted(MODES)}")
        have = set(split(t["skills"]))
        if kit:
            need = {"foundation": ["tdd", "code-review", "pr"], "feature": ["tdd", "code-review", "pr"],
                    "refactor": ["tdd", "code-review", "pr"], "integrate": ["tdd", "code-review", "pr"],
                    "fix": ["diagnosing-bugs", "tdd", "code-review", "pr"],
                    "review": ["code-review"]}.get(mode, [])
            for s_ in need:
                if s_ not in have:
                    W(f"{tid}: {mode}-mode task does not list kit skill '{s_}'")
        if mode == "review":
            if not t["_deps"]:
                W(f"{tid}: review task has empty depends_on; it must depend on every code task it reviews")
            for o in t["_owns"]:
                if not o.startswith(".jules/reports/"):
                    E(f"{tid}: review task owns '{o}'. A review task owns only its report under .jules/reports/")
        if has_seams_col:
            seams = [x for x in split(t.get("seams", "")) if not x.lower().startswith("n/a")]
            if mode in CODE_MODES and not seams and not (t.get("seams", "").strip().lower().startswith("n/a")):
                W(f"{tid}: {mode}-mode task lists no seams. Give seam ids from the spec, or 'n/a: reason'.")
            for sid in seams:
                if spec_seams is not None and sid not in spec_seams:
                    E(f"{tid}: seam '{sid}' is not defined in the spec's Testing Decisions")
    if kit and modes & CODE_MODES and "review" not in modes:
        W("quality kit is on but the plan has no review-mode task in its last wave (references/13-quality-gates.md)")
    if not has_seams_col and kit:
        W("tasks.csv has no 'seams' column; add it so agents test only at pre-agreed seams")

#!/usr/bin/env python3
"""Verify .jules/deps.csv against public registries.

Checks per row: version exists, is stable, is not deprecated/yanked/archived, and how it compares
with the newest stable release. Needs internet. Stdlib only.

Usage:
  python verify_deps.py --deps .jules/deps.csv [--offline] [--max-age-days 14]
Supported ecosystems: npm, pypi, crates, actions, runtime. Others print a MANUAL line with where to look.
Exit code 1 if any ERROR (deprecated, yanked, missing, pre-release, end-of-life).
"""
import argparse
import csv
import datetime as dt
import json
import re
import sys
import urllib.error
import urllib.parse
import urllib.request

UA = {"User-Agent": "jules-swarm-architect-verify-deps/1.0", "Accept": "application/json"}
PRE = re.compile(r"(alpha|beta|rc|canary|nightly|next|dev|snapshot|preview|pre)", re.I)
MANUAL = {
    "go": "https://pkg.go.dev/<module>?tab=versions (check the Deprecated note in go.mod docs)",
    "maven": "https://search.maven.org/ and the project's release page",
    "nuget": "https://www.nuget.org/packages/<id> (look for the Deprecated banner)",
    "gem": "https://rubygems.org/gems/<name>",
    "composer": "https://packagist.org/packages/<vendor>/<name> (abandoned flag)",
    "docker": "the image's Docker Hub or registry tags page; pin a stable tag or digest",
}


def get(url):
    req = urllib.request.Request(url, headers=UA)
    with urllib.request.urlopen(req, timeout=20) as r:
        return json.load(r)


def age_days(iso):
    try:
        d = dt.datetime.fromisoformat(iso.replace("Z", "+00:00"))
        if d.tzinfo is None:
            d = d.replace(tzinfo=dt.timezone.utc)
        return (dt.datetime.now(dt.timezone.utc) - d).days
    except Exception:
        return None


def check_npm(pkg, ver, a, out):
    data = get("https://registry.npmjs.org/" + urllib.parse.quote(pkg, safe="@"))
    latest = data.get("dist-tags", {}).get("latest")
    v = data.get("versions", {}).get(ver)
    if not v:
        return out("ERROR", f"{ver} does not exist on npm")
    if v.get("deprecated"):
        out("ERROR", f"{ver} is DEPRECATED: {str(v['deprecated'])[:160]}")
    if latest and latest != ver:
        out("WARN", f"newer stable available: {latest} (pinned {ver})")
    ag = age_days(data.get("time", {}).get(ver, ""))
    if ag is not None and ag < a.max_age_days:
        out("WARN", f"{ver} is only {ag} days old; consider the previous release unless it fixes a vulnerability")
    ld = data.get("versions", {}).get(latest, {}) if latest else {}
    if ld.get("deprecated"):
        out("ERROR", f"the whole package looks deprecated: {str(ld['deprecated'])[:160]}")


def check_pypi(pkg, ver, a, out):
    data = get(f"https://pypi.org/pypi/{urllib.parse.quote(pkg)}/json")
    info = data["info"]
    files = data.get("releases", {}).get(ver)
    if not files:
        return out("ERROR", f"{ver} does not exist on PyPI")
    if all(f.get("yanked") for f in files):
        out("ERROR", f"{ver} is YANKED")
    if any("Inactive" in c for c in info.get("classifiers", [])):
        out("ERROR", "package is classified Development Status :: 7 - Inactive")
    if info.get("yanked") and info.get("version") == ver:
        out("ERROR", "current release is yanked")
    if info["version"] != ver:
        out("WARN", f"newer stable available: {info['version']} (pinned {ver})")
    ag = age_days(files[0].get("upload_time_iso_8601", ""))
    if ag is not None and ag < a.max_age_days:
        out("WARN", f"{ver} is only {ag} days old")


def check_crates(pkg, ver, a, out):
    data = get("https://crates.io/api/v1/crates/" + urllib.parse.quote(pkg))
    vs = {v["num"]: v for v in data.get("versions", [])}
    if ver not in vs:
        return out("ERROR", f"{ver} does not exist on crates.io")
    if vs[ver].get("yanked"):
        out("ERROR", f"{ver} is YANKED")
    latest = data["crate"].get("max_stable_version")
    if latest and latest != ver:
        out("WARN", f"newer stable available: {latest} (pinned {ver})")
    ag = age_days(vs[ver].get("created_at", ""))
    if ag is not None and ag < a.max_age_days:
        out("WARN", f"{ver} is only {ag} days old")


def check_actions(pkg, ver, a, out):
    repo = get("https://api.github.com/repos/" + pkg)
    if repo.get("archived"):
        out("ERROR", "repository is ARCHIVED (unmaintained)")
    try:
        rel = get(f"https://api.github.com/repos/{pkg}/releases/latest")
        tag = rel.get("tag_name", "")
        major = tag.split(".")[0]
        if tag and ver not in (tag, major):
            out("WARN", f"latest release is {tag}; pinned {ver}")
    except urllib.error.HTTPError:
        out("INFO", "no GitHub release found; check tags manually")


def check_runtime(pkg, ver, a, out):
    cycles = get(f"https://endoflife.date/api/{urllib.parse.quote(pkg)}.json")
    row = next((c for c in cycles if str(c.get("cycle")) == ver), None)
    if not row:
        return out("ERROR", f"cycle {ver} not found for {pkg}")
    eol = row.get("eol")
    if eol is True or (isinstance(eol, str) and eol <= dt.date.today().isoformat()):
        out("ERROR", f"{pkg} {ver} is END OF LIFE ({eol})")
    elif isinstance(eol, str):
        out("INFO", f"supported until {eol}; lts={row.get('lts')}")
    newest_lts = next((c for c in cycles if c.get("lts")), None)
    if newest_lts and str(newest_lts["cycle"]) != ver:
        out("WARN", f"newest LTS cycle is {newest_lts['cycle']}; pinned {ver}")


CHECKS = {"npm": check_npm, "pypi": check_pypi, "crates": check_crates,
          "actions": check_actions, "runtime": check_runtime}


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--deps", required=True)
    ap.add_argument("--offline", action="store_true", help="syntax checks only")
    ap.add_argument("--max-age-days", type=int, default=14)
    a = ap.parse_args()

    errors = 0
    with open(a.deps, newline="", encoding="utf-8") as f:
        rows = [r for r in csv.DictReader(f) if (r.get("ecosystem") or "").strip()
                and not r["ecosystem"].strip().startswith("#")]
    for r in rows:
        eco, pkg, ver = r["ecosystem"].strip().lower(), r["package"].strip(), r["version"].strip()
        lines = []

        def out(level, msg):
            nonlocal errors
            lines.append(f"    {level}: {msg}")
            if level == "ERROR":
                errors += 1

        if re.search(r"[\^~*<>=|]|latest|\.x$", ver):
            out("ERROR", f"{ver} is a range or tag, pin an exact version")
        if PRE.search(ver) and eco != "docker":
            out("ERROR", f"{ver} looks like a pre-release")
        if not a.offline:
            fn = CHECKS.get(eco)
            if fn:
                try:
                    fn(pkg, ver, a, out)
                except urllib.error.HTTPError as e:
                    out("ERROR" if e.code == 404 else "WARN", f"registry returned HTTP {e.code}")
                except Exception as e:
                    out("WARN", f"could not check ({e.__class__.__name__}: {e})")
            else:
                out("MANUAL", MANUAL.get(eco, "check the official registry and release notes"))
        print(f"{eco}:{pkg}@{ver}" + ("  ok" if not lines else ""))
        for ln in lines:
            print(ln)
    print(f"\nRESULT: {'FAIL' if errors else 'OK'} ({len(rows)} packages, {errors} error(s))")
    return 1 if errors else 0


if __name__ == "__main__":
    sys.exit(main())
