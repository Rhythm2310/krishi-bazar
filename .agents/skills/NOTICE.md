# Notice: skills adapted from mattpocock/skills

The skills `tdd`, `code-review`, `diagnosing-bugs`, `codebase-design` and `pr` in this folder are adapted for unattended, parallel Jules sessions from https://github.com/mattpocock/skills (MIT licence). `domain-language` is a swarm-side reading of the upstream `domain-modeling` discipline. The `pr` skill's upstream credits Dex Horthy (HumanLayer, `show-me` skill) for its shape.

Adaptation changes, applied to every skill: questions to a human became pre-agreed items in the task file; sub-agents became sequential passes; the issue tracker became the files under `.jules/`; slash-command hand-offs became "read that skill's SKILL.md".

The upstream licence text governs the originals. When committing, replace the line below with the verbatim text of https://github.com/mattpocock/skills/blob/main/LICENSE.
